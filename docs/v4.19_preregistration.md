# ECF v4.19 — Builder-Language Genesis Preregistration

Date: 2026-10-10
Status: FROZEN BEFORE ANY v4.19 EXPERIMENT
Base: `main` @ `1245eac568a31b87a3f60470f64bcaa8121bd279` (v4.18.5)

## Research question

Given a deliberately incomplete representation-builder language `L0`, can FLF-ECF use only residual failures generated by its own prediction/compression/intervention model to synthesize a new operator that is not present in `L0`, extend the language to `L1 = L0 + g`, and close a measurable fraction of the `B0 -> B1` oracle gap on frozen held-out worlds?

A PASS is limited to preliminary evidence of operator-level language extension in synthetic worlds. It is not evidence of mathematics genesis, AGI, unrestricted language invention, or ontology-free learning.

## L0: deliberately incomplete builder language

`L0` may build scalar or vector features only from:

- `identity(x)`
- `lag(x, 1)`
- `diff(x, 1)`
- `filter_mean(x, width)` with width in `{2, 3, 5}`
- `product(x, y)`
- affine normalization fitted only on the training split
- finite concatenation of existing `L0` features

`L0` explicitly does **not** contain:

- circular unwrapping / phase-unwrapping operators,
- rank-gated history operators,
- templates, flags, enum values, or helper functions named after either missing operator,
- direct access to world-family IDs, latent state, hidden mechanism, target operator IDs, oracle feature values, or frozen-test metadata.

`L0` is frozen for all baselines and all test evaluation.

## Primitive synthesis DSL

The synthesis engine receives only typed low-level array primitives. It searches syntax trees; it is not given missing-operator templates.

Types:

- `ScalarSeries[T]`: length-`T` real-valued sequence
- `BoolSeries[T]`: length-`T` Boolean sequence
- `Scalar`: real scalar
- `IntScalar`: integer scalar

Primitive constructors:

1. `lag(series, k)` where `k in {1,2,3}`
2. `diff(series, k)` where `k in {1,2}`
3. `cumsum(series)`
4. `filter_mean(series, w)` where `w in {2,3,5}`
5. `rank01(series, w)` where `w in {5,9}`; causal rolling percentile rank in `[0,1]`
6. `threshold_gt(series, q)` where `q in {0.25,0.5,0.75}`
7. `threshold_lt(series, q)` with same `q`
8. `modulo(series, p)` where `p in {1.0, 2.0, 6.283185307179586}`
9. `product(series_a, series_b)`
10. `interaction(series_a, bool_b)` (Boolean mask cast to `{0,1}` then multiplied)
11. `negate(series)`
12. `abs(series)`
13. `add(series_a, series_b)`
14. `subtract(series_a, series_b)`

No macro may expand directly to a missing operator. Search is over compositions only.

### Search grammar constraints

- maximum synthesis depth: `6`
- maximum AST nodes: `11`
- maximum candidate programs evaluated per residual episode:
  - T0: `200`
  - T1: `2,000`
  - T2: `20,000`
- typed invalid programs do not count toward the evaluation budget; all semantically evaluated valid candidates do.
- candidate equivalence is functional, not syntactic: on the synthesis training trace, programs with identical outputs up to `1e-9` are one equivalence class.
- MDL cost is `AST_nodes + 0.25 * distinct_primitives + 0.5 * learned_constants`.

## Missing operators in the benchmark generator

The benchmark generator contains two hidden operator families. Their implementations are isolated in the world-generation layer and never imported by learner/synthesis modules.

### M1 / W-Circular

Hidden mechanism: a circularly wrapped sensor is generated from a continuously evolving latent phase. The useful missing representation is the causal unwrapped phase increment, which requires a composition containing at minimum a wrap-sensitive transform and accumulation. The shortest accepted primitive-DSL representation must have synthesis depth >= 4.

World family `W-Circular`:
- observations: continuous multichannel sensor streams including one wrapped angular-like channel plus distractors;
- actions: continuous actuator vectors;
- rewards/next-observation dynamics depend on the unwrapped directional trend;
- `L0` cannot directly express the needed wrap-crossing correction.

### M2 / W-RankInteraction

Hidden mechanism: the predictive/interventional effect depends on whether one sensor is in a high causal rolling rank regime and on a lagged interaction with a second sensor. The shortest accepted primitive-DSL representation must have synthesis depth >= 4.

World family `W-RankInteraction`:
- observations: continuous multichannel sensor streams with monotone distortions and distractors;
- actions: continuous actuator vectors;
- rewards/next-observation dynamics depend on a causal rolling rank gate multiplied by a lagged second stream;
- `L0` has fixed local means/diffs/products but no rolling-rank operator, so it cannot directly express the required invariance.

### Null family W-Null

`W-Null` is fully representable by `L0`. Its dynamics use only identity, lag-1, diff-1, moving mean, and pairwise product structure. A new operator should not be admitted.

## Anti-circularity rules

### Reachability audit

Before T1:
1. exhaustive bounded enumeration through depth `3` must fail to produce a functionally equivalent representation for each hidden operator on at least `12` independently generated diagnostic traces;
2. at least one depth `>=4` composition in the primitive DSL must be able to represent each hidden mechanism up to normalized RMSE `<= 0.02` on those diagnostic traces;
3. the best `L0` approximation must have normalized RMSE `>= 0.20` on the same traces.

Failure of any reachability condition is a benchmark-design failure, not a model failure; T2 may not proceed without a dated preregistration amendment and fresh seeds.

### Information barrier

The learner/synthesizer may read only:
- observations,
- actions,
- scalar rewards,
- its own predictions,
- residuals derived from those quantities,
- its own representation/compression statistics.

The operator-proposal trigger is:
`trigger_score = z(residual_autocorrelation) + z(intervention_effect_inconsistency) + z(compression_gap)`.
A synthesis episode is permitted only when `trigger_score >= 2.5`.

World-family IDs, hidden operator IDs, hidden latent variables, oracle features, generator code paths, and frozen-test seed lists must not be passed into learner or candidate scoring.

Tests must inspect learner-facing function signatures and forbidden identifier strings.

### Frozen evaluation

T2 frozen seeds are evaluated once. Interrupted shards may resume from checkpoints, but completed seed records are immutable and idempotently skipped. If frozen results have been viewed, any code/gate/budget change requires a dated amendment and a completely fresh frozen seed set.

### T0 smoke

- maximum 2 synthesis episodes / seed
- purpose: executable-path and checkpoint validation only
- no scientific verdict

### T1 pilot

### T2 full frozen
- 24 frozen seeds per family
- 20,000 candidate evaluations / residual episode

## Baselines and controls

- `B0`: v4.18.5 builder restricted to `L0`; no language extension.
- `B1`: oracle ceiling with `L0` plus the hand-coded hidden operator in the benchmark-only oracle module.
- `B2`: equal-budget random primitive-DSL compositions; no residual-guided candidate priority.
- `B3-shuffled`: residual trigger inputs independently shuffled within each trace before trigger/candidate scoring.
- `B3-disabled`: trigger disabled; no synthesis proposal.
- `C-actuator-shuffle`: actuator correspondence shuffled while preserving action marginals.
- `C-noise`: pure-noise observations/rewards with matched dimensions and marginal scales.
- `C-null`: `W-Null`; no missing operator is needed.
- operator ablation: after acceptance, remove the synthesized operator and refit under the same downstream budget.

## Primary metrics

For each family/seed compute:

1. `B0_error`, `B1_error`, `L1_error` on frozen held-out prediction/control target.
2. fraction of oracle gap closed:
   `gap_closed = (B0_error - L1_error) / max(B0_error - B1_error, 1e-12)`,
   clipped only for reporting to `[-1, 1.5]`; statistical tests use the unclipped value.
3. held-out-family transfer: apply the functionally rediscovered operator to a disjoint world variant requiring the same hidden mechanism.
4. ablation damage: `(ablated_error - L1_error) / max(L1_error, 1e-12)`.
5. functional rediscovery: pairwise agreement of accepted operator outputs after per-trace affine normalization; syntactic identity is irrelevant.
6. MDL improvement: `description_length(B0 residuals) - description_length(L1 residuals) - operator_description_cost`.
7. false acceptance on `W-Null`, shuffled-actuator worlds, and pure-noise worlds.

Lower error is better. Control metrics are converted to `error = 1 - normalized_reward` before gap calculations.

## Frozen gates

All primary gates are evaluated on T2 only. Gates are never lowered.

For each continuous metric below, use a seed-level nonparametric bootstrap with `20,000` bootstrap resamples and report the percentile 95% CI. The required comparison is the **lower bound** of the CI unless stated otherwise.

### G1 Oracle-gap closure
For each non-null family separately:
- mean `gap_closed >= 0.35`, and
- bootstrap 95% CI lower bound `>= 0.25`.

### G2 Transfer
For each non-null family separately:
- mean transfer gap-closed `>= 0.25`,
- bootstrap 95% CI lower bound `>= 0.15`.

### G3 Ablation causality
For each non-null family separately:
- mean ablation damage `>= 0.20`,
- bootstrap 95% CI lower bound `>= 0.10`.

### G4 Functional rediscovery
Across accepted operators within each non-null family:
- median pairwise functional similarity `>= 0.90`,
- bootstrap 95% CI lower bound on the median `>= 0.85`.

### G5 MDL/compression
For each non-null family:
- mean net MDL improvement `> 0`,
- bootstrap 95% CI lower bound `>= 0.02 * B0_residual_description_length`.

### G6 Residual guidance beats random search
For each non-null family:
- mean `(gap_closed_residual - gap_closed_B2) >= 0.10`,
- bootstrap 95% CI lower bound `>= 0.05`.

### G7 Trigger control
For each non-null family:
- B3-shuffled mean gap-closed must be at least `0.10` lower than residual-guided,
- bootstrap 95% CI lower bound of the paired difference `>= 0.05`.
- B3-disabled cannot accept any new operator by definition.

### G8 Null false acceptance
On `W-Null`:
- new-operator false-acceptance rate `<= 0.05`,
- exact Clopper-Pearson 95% CI upper bound `<= 0.15`.

### G9 Corruption/noise safety
For each of `C-actuator-shuffle` and `C-noise`:
- acceptance rate `<= 0.10`,
- exact 95% CI upper bound `<= 0.20`,
- no positive claim may rely on performance from accepted operators in these controls.

### G10 Reachability / non-approximation
The anti-circularity reachability audit above must pass exactly; any failure => v4.19 `FAIL (benchmark invalid)`.

### Overall verdict

`PASS` iff **every** G1-G10 gate passes and all v4.18 tests remain green.
`FAIL` iff T2 is complete and any gate fails.
`INCONCLUSIVE (under-powered)` iff T2 is incomplete, fewer than preregistered seeds are available, or any budget is silently/externally truncated.

No gate may be moved after T2 results are observed.

## Bootstrap/statistical procedure

- seed is the resampling unit;
- `20,000` bootstrap samples;
- percentile 95% confidence intervals;
- paired comparisons resample paired seed rows;
- no per-timestep pseudo-replication;
- `W-Null` and corruption acceptance-rate bounds use exact binomial Clopper-Pearson intervals;
- no multiple-comparison correction is used because the overall gate is conjunctive: all preregistered gates must pass.

## Amendment A1 — 2026-10-10 — benchmark/interface correction before T1/T2

### Reason

T0 attempt 1 on development seeds exposed two benchmark-design defects before any T1 or frozen T2 evaluation:

1. action vectors were available to the residual trigger but were accidentally omitted from the predictor feature environment, despite the original information barrier explicitly allowing actions;
2. `W-RankInteraction` produced an unstable oracle ceiling on T0 development seeds (including one seed where `B1` was slightly worse than `B0`), invalidating the intended oracle-gap metric.

No frozen T2 seed has been evaluated. No gate, threshold, bootstrap rule, synthesis budget, DSL primitive, maximum depth, maximum nodes, or acceptance criterion is lowered or relaxed by this amendment.

### Interface correction

For all post-amendment runs, the learner-visible environment contains the observed sensor channels plus the continuous action channels as anonymous scalar series:

- observations: `x0, x1, ...`
- actions: `u0, u1, ...`

The learner still receives no world-family ID, hidden state, hidden operator ID, oracle feature, generator path, or frozen-seed metadata. Action channels enter `L0` and synthesized expressions only through the already-preregistered generic primitives; no new primitive or operator-specific template is added.

### W-RankInteraction benchmark correction

The benchmark-only generator is changed only to make the preregistered oracle meaningfully identifiable and to stabilize the `B0 -> B1` ceiling:

- hidden rank-interaction contribution coefficient: `1.6 -> 4.0`;
- observation/reward additive noise scale in this family: `0.06 -> 0.04`.

The hidden operator definition itself is unchanged. `L0`, the synthesis DSL, residual trigger formula, candidate acceptance rule, and all G1-G10 thresholds are unchanged.

## Amendment A2 — 2026-10-10 — restore missing-operator necessity in W-Circular before T1/T2

### Reason

Post-A1 T0 on fresh development seeds showed that exposing action streams correctly made `W-Circular` too easy for `L0`: `B0` and `B1` errors were nearly equal and the residual trigger stayed below `2.5`. This violates the intended benchmark property that the missing representation be necessary.

No T1 or frozen T2 evaluation has occurred. No gate, threshold, bootstrap rule, DSL primitive, search depth/node limit, synthesis budget, acceptance rule, or statistical rule is changed.

### W-Circular benchmark correction

Only the benchmark generator is changed.

The latent circular phase increment is now driven by a persistent stochastic velocity that is only partially influenced by action:

- `drive[t] = 0.85 * drive[t-1] + 0.22 * Normal(0,1) + 0.10 * tanh(u0[t])`
- `step[t] = 0.22 * tanh(drive[t])`
- wrapped observation remains `x0[t] = phase[t] mod 1.0`
- reward/prediction target uses `1.8 * circular_delta(x0) + 0.08 * u0 + Normal(0,0.04)`

This increases wrap crossings and makes the stochastic component impossible to reconstruct from action alone while leaving the hidden operator definition unchanged.

`W-RankInteraction` remains exactly as amended in A1.

## Amendment A3 — 2026-10-11 — oracle-ceiling integrity and fresh pre-T2 protocol

### Reason

The repaired post-G10 A2 T1 development pilot exposed a control-implementation defect before any frozen T2 seed was evaluated. In `W-RankInteraction`, the benchmark-only oracle expression was present in the feature pool but the training-only top-three feature selector frequently omitted it. Consequently `B1` was exactly equal to `B0` on many development seeds, and the preregistered oracle-gap denominator could collapse toward `1e-12`. This makes `B1` fail to function as an oracle ceiling and can produce numerically huge, scientifically meaningless `gap_closed` values.

This amendment is committed after development-only T1 observations and **before any frozen T2 evaluation**. All prior A2 frozen ranges remain unused. No G1-G10 threshold is lowered, no synthesis primitive is added, no missing-operator template is introduced, and no candidate/search budget is reduced.

### Uniform extension-slot rule

For all post-A3 downstream v4.18.5 adapter arms:

- `B0` selects all three feature slots from `L0` only.
- Whenever exactly one extension expression is supplied to an arm (`B1` oracle, `L1` residual-guided, `B2` random-composition, or `B3-shuffled`), that extension occupies exactly one of the three feature slots.
- The remaining two slots are selected from `L0` using training data only and the same selector/scoring rule for every arm.
- The same unchanged v4.18.5 `G`, `Model`, mutation, crossover, and 48-model downstream evaluation budget is used for every arm.
- Candidate acceptance remains exactly the preregistered validation/MDL rule. For `L1/B2/B3`, forcing a candidate into one slot does not force acceptance; a harmful candidate is rejected and the arm falls back to `B0`.
- `B1` is benchmark-only and does not expose the oracle expression, family identity, hidden state, or oracle output to the learner/synthesizer. The oracle is used only after candidate search for the ceiling calculation.

This rule makes `L0 + g` literal and symmetric across all extension arms while restoring `B1` as a meaningful ceiling.

### G0 — oracle-ceiling integrity (new stricter prerequisite)

For each non-null family separately on frozen T2, define seed-level:

`oracle_gain = (B0_error - B1_error) / max(B0_error, 1e-12)`.

Require both:

- mean `oracle_gain >= 0.10`, and
- seed-level nonparametric bootstrap 95% CI lower bound `>= 0.05` using the same preregistered `20,000` resamples.

`PASS` now requires **G0 and every unchanged G1-G10 gate**. If G0 fails after complete T2, the verdict is `FAIL (oracle ceiling / benchmark invalid)`; frozen results are not reinterpreted or filtered.

G1-G10 thresholds, definitions, and bootstrap/binomial rules remain unchanged except for the previously required clarification that G4 resamples accepted operator **seeds** and recomputes the pairwise functional-similarity median inside each bootstrap replicate; pairwise similarities are never treated as independent resampling units.

### Exact residual-trigger estimators

To eliminate the implementation ambiguity found during the pre-T2 source audit, the already-preregistered three-component trigger is operationally frozen as follows, using learner-visible quantities only:

1. `z(residual_autocorrelation)`: absolute Fisher-z score of residual lag-1 correlation;
2. `z(intervention_effect_inconsistency)`: maximum absolute Fisher-z score between each anonymous action channel and the residual;
3. `z(compression_gap)`: `sqrt(G^2)` likelihood-ratio statistic comparing the 2x2 median-sign residual-transition table with its iid-sign independence model.

The trigger remains the **sum** of these three terms and remains open only at `trigger_score >= 2.5`. No hidden benchmark quantity enters any term.
