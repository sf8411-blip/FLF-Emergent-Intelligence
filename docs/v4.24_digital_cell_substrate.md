# ECF v4.24 — Minimal digital-cell substrate

v4.24 begins a separate experimental line closer to the proposed cell
architecture. It defines a non-neural data model for a cell's structural
genome, local state, bounded experience memory, host resource budget and
explicit neighbor graph.

## Deliberate constraints

- A cell has no built-in human arithmetic, scientific theory or language model.
- A received experience is stored as evidence, not treated as truth.
- Imported validation labels are cleared. A receiver must validate locally.
- Compute and energy budgets are hard gates for memory insertion.
- Network exchange is limited to explicitly connected neighbors.
- Memory capacity is bounded, with deterministic oldest-entry eviction.
- The genome is currently descriptive metadata; this version does not yet
  mutate it or claim that the system discovers its own mathematics.

## Current limits

This is a testable substrate, not a complete learning algorithm. It has no
autonomous relation discovery, no scientific world model, no secure distributed
consensus, no cryptographic identity, and no production IoT transport. The
resource counters are software-level budgets, not direct hardware telemetry.
The next experiment should add local re-evaluation of received claims and
compare networked cells against isolated and shuffled-message controls.
