# ECF v4.18 research log — Self-Evolving Representation Builders

## Goal
Evolve the representation-building procedure itself rather than tune one fixed representation. A genome controls segmentation, temporal windowing, feature construction, state cardinality, actuator partitioning, normalization, transition target, control policy, intervention-equivalence mode, and internal complexity preference.

The benchmark learner does not receive hidden simulator states or actuator classes.

## Predeclared gates (never relaxed)

- prediction gain vs fixed builder >= 8%
- prediction gain vs equal-budget random builder search >= 3%
- control gain vs fixed builder >= 0.08
- evolutionary gain over initial population >= 0.03
- mutation ablation gap >= 0.005
- crossover ablation gap >= -0.005
- shuffled-actuator degradation >= 50%
- pure-noise degradation >= 100%
- independent operational rediscovery >= 0.80

## Negative results preserved

1. **v4.18 initial scalar evolution — FAIL.** Prediction improved over a hand-coded builder, but control gain, shuffled/noise separation, and equal-budget random-search superiority were insufficient.
2. **v4.18.1 — FAIL.** Adding delta targets and richer policies improved prediction but still failed equal-budget random search, control, noise separation, and rediscovery.
3. **v4.18.2 — FAIL.** A more identifiable continuous world made mutation/crossover useful and shuffled semantics detectable, but random search transferred better and pure-noise separation remained insufficient.
4. **v4.18.3 — FAIL.** Effect-conditioned actuator equivalence plus Pareto selection improved semantic-shuffle safety, but control stayed weak.
5. **Control bug found.** The online loop used the pre-intervention sensor `x_t` as the next decision state instead of the post-intervention sensor `y_t`, producing a one-step stale policy. This was fixed without changing gates.
6. **v4.18.4 bounded screen — FAIL.** After the bug fix, control improved strongly, but the two-run screen failed mutation and rediscovery gates.
7. **v4.18.5 three-run screen — FAIL only on rediscovery.** Every other gate passed; rediscovery was 2/3 = 0.667. Two additional independent runs were therefore added without changing thresholds.

## Valid v4.18.5 result

Five main evolutionary runs and three matched ablation runs produced:

- prediction gain vs fixed builder: **64.04%**
- prediction gain vs equal-budget random search: **37.39%**
- control gain vs fixed builder: **+0.6942**
- evolutionary gain: **+0.3081**
- mutation gap: **+0.3936**
- crossover gap: **+0.6799**
- shuffled-actuator degradation: **+256.17%**
- pure-noise degradation: **+123.72%**
- independent operational rediscovery: **0.80**
- gate: **PASS**

## Interpretation
This is bounded evidence that an evolutionary population can improve a *procedure for constructing operational representations* across synthetic continuous worlds, and that the resulting procedure depends on coherent intervention semantics rather than only on sensor smoothness. It is not evidence of unrestricted meta-learning, general intelligence, or mathematics emerging without inductive bias. The genome language and evolutionary operators are still human-designed.

## Next unresolved prior
The next stage should target **builder-language genesis**: v4.18 evolves programs inside a supplied genome language. v4.19 should test whether the system can create/retain new builder operators that were not present in that initial language, under compression, transfer, falsification, and independent rediscovery gates.
