# v4.20 — Empirical Invariance Discovery

## Purpose
This increment tests whether the bounded expression language can distinguish
structural properties from predictive fit. It adds empirical checks of
$f(T(x)) \approx f(x)$ under explicitly supplied transformations.

## Scope
- Deterministic transformations: reflection, translation, and nonzero scaling.
- Whitelist expression evaluation inherited from v4.19.
- Normalized RMS discrepancy and per-transformation failure records.
- No language mutation: reports are evidence, not automatic promotion.

## Critical interpretation
Passing finite tests is **not a proof** of invariance over all inputs. The result
is conditional on the sampled domain, chosen transformations, floating-point
arithmetic, and tolerance. A later stage should search for counterexamples,
repeat on held-out domains, and distinguish invariance from equivariance
($f(Tx)=S f(x)$).

## Reproducibility
Run the full suite with:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

The tests use fixed deterministic grids and contain both positive and negative
controls: $x^2$ should be reflection-invariant, $x$ should not, and $x^2$ should
not be translation-invariant.
