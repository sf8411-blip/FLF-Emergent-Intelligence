# گزارش نهایی ECF v4.19 — Builder-Language Genesis

## حکم نهایی

**FAIL**

این نتیجه یک شکست تمیز و از نظر علمی معتبر است: هر ۱۲۰ seed از پیش ثبت‌شده در T2 اجرا شد، بودجه‌ها کاهش پیدا نکرد، CI قبل و بعد از frozen evaluation سبز بود، ۲۰٬۰۰۰ bootstrap برای CIها اجرا شد و هیچ Gate بعد از مشاهدهٔ نتیجه جابه‌جا نشد.

ادعای محدود قابل دفاع این است:

> v4.19 نشان می‌دهد که یک DSL محدود می‌تواند در خانوادهٔ مصنوعی Circular ویژگی‌های مفیدی خارج از L0 بسازد و بخش بزرگی از شکاف تا oracle را ببندد؛ اما آزمون frozen فرضیهٔ قوی‌ترِ «گسترش قابل‌اعتماد، residual-guided، پایدار و انتخاب‌گرِ زبان در سطح operator» را رد می‌کند.

این نتیجه هیچ ادعایی دربارهٔ math genesis، AGI یا اختراع نامحدود زبان ندارد.

## علت‌های اصلی شکست

### 1. Useful feature synthesis با language extension یکی گرفته شد
در Null world که اصولاً operator جدید لازم نیست، ۵۸.۳٪ seedها operator جدید پذیرفتند. این یعنی admission rule الزام نکرده بود که candidate از نظر تابعی واقعاً خارج از closure/span زبان L0 باشد. یک composition جدید می‌تواند مفید یا فشرده باشد، ولی این به‌خودی‌خود «گسترش زبان» نیست.

### 2. Residual trigger در برابر semantic corruption ایمن نیست
در actuator-shuffle، ۹۵.۸٪ seedها operator پذیرفتند. residual autocorrelation و compression gap می‌توانند حتی وقتی correspondence مداخله‌ای شکسته شده بالا باشند. بنابراین scalar trigger برای causal admission کافی نیست.

### 3. Functional rediscovery ضعیف است
در Circular، با وجود gap closure بسیار بالا، median functional similarity فقط 0.164 است. سیستم ظاهراً surrogateهای متفاوت و task-specific پیدا می‌کند، نه یک operator عملیاتی مشترک که مستقل از syntax دوباره کشف شود.

### 4. Residual guidance از random search بهتر نیست
در Circular، `residual_minus_random = -0.017`. بنابراین بخش «use only its own residual failures to guide synthesis» در frozen test پشتیبانی نشد. DSL قدرت بیان کافی دارد، اما search guidance مزیت معنادار نشان نداد.

### 5. RankInteraction recovery بسیار ضعیف است
با oracle معتبر، تنها ۳/۲۴ پذیرش رخ داد. Search space یا scoring/admission برای ساختارهای rank-gated interaction ناکافی است.

### 6. Pure noise کنترل سالمی بود
در pure noise هیچ operator پذیرفته نشد. بنابراین مسئله این نیست که سیستم هر چیزی را می‌پذیرد؛ مشکل دقیق‌تر، **structured false discovery** است.

## تلاش‌ها و bugهای شکست‌خورده که حفظ شدند

- T0 attempt 1: action channels در predictor جا افتاده بودند و RankInteraction oracle ناپایدار بود؛ A1 قبل از T1/T2 ثبت شد.
- A1 Circular necessity failure: پس از exposure درست actions، benchmark بیش از حد L0/action-explainable شد؛ A2 و seedهای تازه قبل از inference تعریف شدند.
- A2 smoke: بودجهٔ ۲۰۰ candidate recovery قابل‌اعتماد نداد؛ غیرinferential بود.
- pre-T1 baseline mismatch: baseline اولیه با `B0=v4.18.5 on L0 only` یکسان نبود؛ قبل از frozen اصلاح شد.
- G10 infrastructure interruption: runner shutdown؛ نتیجهٔ علمی استخراج نشد و audit بدون تغییر تکرار شد.
- trigger mismatch: sign-change proxy با compression-gap preregistered یکسان نبود؛ قبل از frozen اصلاح شد.
- G4 bootstrap bug: pairwise similarities به‌اشتباه به‌عنوان واحد مستقل bootstrap شده بودند؛ قبل از T2 به seed-level bootstrap اصلاح شد.
- A2 oracle-slot defect: oracle feature ممکن بود در selection حذف شود؛ A3 با extension slot متقارن و seedهای تازه ثبت شد.
- A3 YAML quoting bug: صرفاً infrastructure؛ هیچ experiment قبل از repair اجرا نشد.

## نتیجهٔ تثبیت‌شده در برابر ادعاهای اثبات‌نشده

### تثبیت‌شده
- L0 عمداً برای دو hidden family ناکافی بود و G10 این موضوع را بررسی کرد.
- DSL در Circular می‌تواند featureهای خارج از L0 بسازد که prediction/transfer را بهبود دهند و ablation آنها آسیب ایجاد کند.
- این مزیت در pure noise ظاهر نمی‌شود.
- پروتکل فعلی برای تشخیص «language extension واقعی» specificity کافی ندارد.

### اثبات‌نشده / ردشده در این نسخه
- residual-guided synthesis بهتر از equal-budget random search است.
- یک operator مشترک و functionally stable در seedهای مختلف دوباره کشف می‌شود.
- admission rule می‌تواند نیاز واقعی به operator جدید را از structured corruption یا L0-sufficient worlds تفکیک کند.
- v4.19 math genesis، AGI یا unrestricted language invention را نشان می‌دهد.

## محدودیت‌ها و مسیر علمی بعدی

هر repair آینده باید نسخه/Amendment جدید و frozen seedهای تازه داشته باشد؛ A3 نباید دوباره tune شود. پیشنهادهای بعدی:

1. `functional novelty gate`: candidate فقط وقتی language extension محسوب شود که از closure/span L0 به‌طور آزمون‌پذیر خارج باشد.
2. `intervention challenge`: residual proposes; new intervention verifies. پذیرش باید با مداخلهٔ مستقل causal challenge شود.
3. `cross-world semantic canonicalization`: operator پیش از admission باید در چند world مستقل semantics مشترک نشان دهد.
4. تفکیک رسمی دو hypothesis: `useful feature synthesis` در برابر `operator-level language extension`.
5. قبل از frozen بعدی، residual-guided search باید در dev با بودجهٔ برابر random-search را شکست دهد؛ نه با تغییر Gate، بلکه به‌عنوان شرط صرف هزینهٔ frozen جدید.
