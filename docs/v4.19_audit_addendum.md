## Consequences for v4.20 instrument repair

The audit changes no frozen result, but it identifies instrument defects that v4.20 DEV work must repair before any future preregistration is frozen:

1. `useful feature` and `language novelty` must be separate tests; admission needs an explicit L0-span novelty criterion.
2. corruption controls must actually destroy the mechanism rather than merely corrupt a small nuisance action term.
3. trigger thresholds must be calibrated from the learner's own block-permuted residual null, not fixed at 2.5.
4. functional comparison must use held-out world traces and predictive substitutability, not iid synthetic signatures alone.
5. equal-budget random controls need the same grammar as guided search and two separate selection rules (`B2a`, `B2b`).
6. continuous fitted constants must replace benchmark-matched grids and must incur the preregistered MDL charge.
7. gap closure must use pooled ratio-of-sums after oracle-validity filtering; ablation must be in-model and no-refit.
